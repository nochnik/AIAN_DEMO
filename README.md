# KMG.AIAN — интро-показ

**Показ живёт здесь: https://nochnik.github.io/AIAN_DEMO/**

Интро-лента перед живой демонстрацией ИИ-ассистента KMG.AIAN и финальный
слайд эффектов. Открывается ссылкой в браузере — корень сайта сам
перенаправляет на `показ.html`.

## Управление

| Клавиша | Действие |
|---|---|
| `→` · пробел · клик | следующий такт |
| `←` | предыдущий такт |
| `End` | сразу финал (после живой демонстрации) |
| `Home` | вернуться на титул |
| `F11` | полный экран — так и показывать |

Курсор мыши прячется сам после 2,5 секунд неподвижности.

Такты идут по клику докладчика; исключение — видеоцепочка: по её окончании
лента сама уходит в пролёт к карте.

## Служебные режимы (репетиции и проверка)

- `?такт=N` — открыть показ сразу с такта N (нумерация с 0);
- `&снимок=1` — все анимации в конечном состоянии (покадровая проверка);
- `&пусто=1` — карта без линий и знака (служебный кадр).

Пример: `https://nochnik.github.io/AIAN_DEMO/показ.html?такт=4`

## Порядок тактов

0. Титул — KMG.AIAN
1. Три вопроса государства
2. Цепочка: добыча → транспортировка → переработка → данные в центр (видео)
3. Пролёт к карте, данные стекаются в Астану
4. Экран ДАЦ: вопрос ИИ → ответ на карте, проблемный регион
5. Решение: поток поставок с запада, отбой тревоги
6. Передача экрана — «Живая демонстрация»
7. Финал: эффекты и ожидаемый результат

## Показ без интернета

Папка репозитория — это весь показ. На месте достаточно:

```bash
python -m http.server 8091
```

и открыть `http://localhost:8091/`. Ничего не собирается, внешних
зависимостей нет: шрифты (`медиа/шрифты/`), анимационная библиотека
(`вендор/gsap.min.js`) и все данные лежат рядом.

## Из чего состоит

| Путь | Что это |
|---|---|
| `показ.html` | вся лента: такты, карта, анимации — один файл |
| `медиа/` | видеоряд (цепочка, мост), титульный фон, рельеф карты, логотип, шрифты |
| `данные/области_кз.json` | точные контуры 20 регионов Казахстана |
| `данные/огни_кз.json` | огни городов для карты |
| `вендор/gsap.min.js` | анимации (самохостится — показ автономен) |
| `index.html`, `.nojekyll` | вход GitHub Pages |

Карта — гибрид: границы областей рисует вектор (точная география),
фактура под ними — генерированный рельеф, обрезанный контуром страны.
Весь текст — HTML-слой поверх, в видеокадры ничего не запекается.
