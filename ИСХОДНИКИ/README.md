# Исходники

Сюда кладутся материалы заказчика и всё, из чего собирается показ: документы,
презентации, брендбук, референсы, снимки, куски видео и звука.

Файлами, а не текстом в переписке: так они не теряются между разговорами и
доступны целиком, а не в пересказе.

Складывать удобно по происхождению, например:

```
ИСХОДНИКИ/
  от_заказчика/     что прислали
  референсы/        на что ориентируемся
  бренд/            логотипы, палитра, шрифты
  черновики/        наши промежуточные материалы
```

Чувствительное — договоры, персональные данные, коммерческие цифры — перед
первым коммитом решить отдельно: что уходит в `.gitignore`, а что можно
хранить в репозитории открыто.
